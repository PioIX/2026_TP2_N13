# Pilares Gastronómicos

## Descripción

Pilares Gastronómicos es un sitio web institucional desarrollado para presentar los servicios de una empresa dedicada a la alimentación escolar,laboral e institucional.

La página tiene como objetivo informar a los usuarios sobre la empresa, sus principales servicios, beneficios, reseñas de clientes y medios de contacto.

## Características

- Diseño moderno y responsivo.
- Sección de presentación de la empresa.
- Catálogo de servicios ofrecidos.
- Beneficios destacados.
- Reseñas de clientes.
- Formulario de contacto funcional mediante Formspree.
- Navegación intuitiva entre secciones.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub
- Formspree

## Estructura del sitio

- **Inicio:** presentación de la empresa.
- **Servicios:** descripción de los servicios gastronómicos.
- **Reseñas:** opiniones de clientes.
- **Contacto:** formulario para consultas.
